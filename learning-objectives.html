Artifact 2 — Design

Learning Objectives

Measurable objectives written to guide instruction and assessment, and how each one maps to a learning activity and an assessment task.

Learning objectives

By the end of the learning experience, teachers will be able to:

  1. Create an effective generative AI prompt for a lesson-planning task by including relevant context, a clear task, learner information, and the desired output format.
  2. Evaluate an AI-generated instructional resource by identifying issues related to accuracy, relevance, learner suitability, and alignment with the lesson objective.
  3. Adapt an AI-generated instructional resource to make it appropriate for a specific group of learners and the intended learning objective.

Alignment between objectives and assessment

Objective Learning activity Assessment
Create an effective AI prompt Examine a weak prompt and improve it Write an effective prompt
Evaluate AI-generated content Review an AI-generated lesson Identify at least 3 issues
Adapt AI-generated content Modify a generated lesson for a particular class Submit an improved version

Instructional strategy

Because the learners are teachers and the topic is practical, the course uses a Demonstration → Guided practice → Independent practice approach, built around a simple learning cycle:

Explain → Demonstrate → Practice → Apply → Reflect

PhaseWhat happens
ExplainIntroduction of the concept
DemonstrateShowing how it is done
PracticeLearner works with an example
ApplyLearner performs the task independently
ReflectLearner considers how they will use it

Course structure

Course title: Using Generative AI Effectively for Lesson Planning
Proposed duration: 15–20 minutes

Module 1 — Using AI for Lesson Planning (2–3 min)

  • What can generative AI do?
  • What generative AI cannot do reliably?
  • The teacher's role

Module 2 — Creating Effective Prompts (5 min)

  • Why prompts matter
  • Components of an effective prompt
  • Weak vs. effective prompts
  • Demonstration

Module 3 — Evaluating AI-Generated Content (5 min)

  • Accuracy
  • Relevance
  • Learner suitability
  • Alignment with objectives

Module 4 — Adapting AI-Generated Content (5 min)

  • Modify
  • Simplify
  • Differentiate
  • Align with learners and objectives

Activity — Apply What You Have Learned (3–5 min)

  • Create a prompt
  • Evaluate the AI output using the standards learnt above
  • Adapt the output

Media strategy

  • Microsoft PowerPoint / Canva — course slides and visual design.
  • Screen recording — demonstrating an AI interaction step by step.
  • Text — key concepts, definitions, and instructions.
  • Icons / diagrams — simplifying concepts and relationships.
  • Short quiz / activity — learner practice and assessment.
